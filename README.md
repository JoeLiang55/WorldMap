🌍 World Country Information Map - Angular Application
Overview
This Angular web application presents an interactive SVG world map that highlights individual countries when hovered over. When a country is selected, it fetches and displays relevant country details from the World Bank API, including name, capital, region, income level, and other data. The application is built as an enhancement to a previous state-level geographic project, now expanded to the global scale.

This project was created using Angular and demonstrates dynamic data handling, SVG interactivity, API integration, and clean routing within a single-page application.

✨ Features
Interactive SVG world map (from SVG Map Resource)

Highlights countries on hover

Click to retrieve and display country-specific data from the World Bank API

Responsive two-column layout (map | country information)

Angular routing redirects from / to /map

Fully componentized Angular project with proper service and routing architecture

Maintains GitLab version control with detailed commit history

🌐 Country Data Displayed
Data is retrieved via the World Bank API and includes:

Country Name (e.g., "Chad")

Capital City (e.g., "N'Djamena")

Region (e.g., "Sub-Saharan Africa")

Income Level (e.g., "Low income")

Two additional properties:

Population

GDP
